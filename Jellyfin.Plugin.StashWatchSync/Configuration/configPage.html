JF To Stash Sync

Turns all synchronization features of this plugin on or off.
Enter the address you use to open Stash, for example http://192.168.1.201:9999.
Enter a key only if your Stash server uses API authentication. You can create or copy it in Stash under Settings → Security → API Keys.
Checks whether Jellyfin can connect to Stash using the address and API key entered above.

Synchronization

Keeps the watched time in Stash up to date with how long videos are actually played in Jellyfin, including unfinished viewing.
Saves the current playback position from Jellyfin to Stash so you can continue the same video in Stash. Finished videos are not given a continue-watching position. Stash keeps one shared position for each video, so the most recent update is used.
Enter one Jellyfin user ID if only that user's playback position should be sent to Stash. Leave this empty to accept updates from any user allowed in the Users section below. If several users watch the same video, Stash keeps the most recently received position.
While a video is playing, the position is sent no more often than this. Default: 60 seconds. The final position is always sent when playback stops.
Smaller position changes are ignored while the video is playing. Default: 20 seconds. The final position is always sent when playback stops.
When you add or remove an actor from Favorites in Jellyfin, the matching performer in Stash is updated too. Actors that are not linked to Stash are skipped.
When a video is added to Favorites in Jellyfin, the matching Stash scene is rated 5 stars. Removing it from Favorites sets the rating to 0.

Jellyfin Web

Adds an O-counter button to the Jellyfin Web player. Each press adds 1 to the O counter of the matching video in Stash and records it in Stash history. Works in Jellyfin Web only. Requires File Transformation 3.x.
Adds an actors button to the Jellyfin Web player. Press it to open a list of actors from the current video, view their photos, and add or remove them from Jellyfin Favorites. Works in Jellyfin Web only and requires File Transformation 3.x.
Shows gender icons for actors on Jellyfin Web video pages and in the actors popup in the player. Supported gender labels are shown as icons; other role text is left unchanged. Works in Jellyfin Web only and requires File Transformation 3.x.
Turns web addresses written in an actor's description into clickable links that open in a new tab. Works in Jellyfin Web only and requires File Transformation 3.x.
If an actor's description contains supported social or profile links, Jellyfin Web shows convenient icons next to the actor's name. Clicking an icon opens that page in a new tab. Supports Instagram, OnlyFans, Patreon, Reddit, Telegram, TikTok, Tumblr, Twitch, VK, WordPress, X/Twitter, YouTube, Bluesky, Facebook and IMDb. Requires File Transformation 3.x.

Jellyfin links in Stash

Periodically adds a link back to the Jellyfin video page to matching scenes in Stash. You can change how often this runs in Jellyfin Dashboard → Scheduled Tasks.
Periodically adds a link back to the Jellyfin actor page to matching performers in Stash. Actors that are not already linked with Stash are skipped.
Enter the address you normally use to open Jellyfin, for example http://192.168.1.201:8096 or https://example.org/jellyfin. This is the address that will be saved in Stash links.
Enter a Jellyfin video ID to add its Jellyfin link to Stash immediately. This can be used even when automatic link synchronization is turned off.
Enter a Jellyfin actor ID to add that actor's Jellyfin link to the matching Stash performer immediately. The actor must already be linked with Stash.

Finding matching videos

When manual Stash search refreshes Jellyfin metadata, also refresh and replace the video's images. Leave this off if you want to keep the existing artwork.
If manual search still cannot find a video, ask Stash to scan the folder containing that file and try again automatically. The path settings below are used when Jellyfin and Stash see the same files under different folder paths.
Lets playback position, watched time, O-counter and automatic link synchronization find the matching Stash video using its file location when a direct link is not available.
When enabled, Jellyfin and Stash file locations are compared using the full path. When disabled, only the filename is used. Full paths are safer when different folders can contain files with the same name.
Use this only if Jellyfin and Stash see the same media under different paths. Example: if Jellyfin sees /mnt/media/Studio/video.mp4, enter /mnt/media.
Using the example above, if Stash sees the file as /data/Studio/video.mp4, enter /data. Leave both path fields empty when Jellyfin and Stash use the same paths.

Users

Leave this empty to synchronize all Jellyfin users. To limit synchronization, enter one or more Jellyfin user IDs separated by commas. This affects playback, favorites, ratings and continue-watching position. Scheduled link tasks are not limited by this setting.
